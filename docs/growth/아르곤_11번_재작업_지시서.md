# 11번 일주 페이지 60장 — 다시 쓰기 (클로드 검토 결과, 2026-10-30)

브랜치: `argon/11-ilju-seo` 그대로 이어서 작업한다(새 브랜치 X). 배포는 클로드가 한다.

## 왜 다시 쓰나
검토에서 잰 수치(현재 `lib/seo/ilju.ts`):

| 항목 | 지금 | 목표 |
|---|---|---|
| 페이지당 본문 글자 수 | 평균 1,761자 (최소 1,683) | **페이지마다 3,500자 이상** |
| 다른 페이지에도 똑같이 나오는 문장 비율 | **67%** (60장 모두에 같은 문장 4개, 50장에 같은 문장 2개) | **15% 이하** |
| 한 페이지 안에서 같은 문장 반복 | 있음 (갑자일주 "서운한 점이 생겼을 때 밤늦게…"가 두 번) | 0 |
| "잘 맞는 일주" 이유 문장 | 다른 짝끼리 글자 하나 안 다르게 같음 (정축·계축) | 짝마다 다른 문장 |

이대로 올리면 검색엔진이 틀로 찍어 낸 글(scaled content)로 보고 순위를 낮출 수 있다. 60장을 "한 장씩 두껍게" 다시 쓴다.

## 다시 쓰는 규칙
1. **페이지마다 고유한 근거를 쓴다.** 일주마다 다른 것: 위 글자(10종)와 아래 글자(12종)의 조합, 띠 동물, 계절감, 위·아래 기운의 관계(서로 돕는지·부딪치는지·같은지). 이 조합에서만 나오는 장면을 쓴다(예: 갑자 = 겨울밤 물가의 큰 나무 → "밤에 생각이 깊어지는 연애").
2. **섹션 4개는 그대로**(연애 성향 / 속마음 표현 방식 / 이별·재회 패턴 / 잘 맞는 일주 3개). 각 섹션 소제목 2개 이상, 소제목 아래 본문은 2문단·250자 이상.
3. **새로 넣을 것** (섹션 안에 소제목으로):
   - "○○일주 연애에서 자주 생기는 상황 3가지" — 구체적 장면(카톡 답장, 약속 취소, 기념일 등). 일주마다 다른 장면.
   - "○○일주에게 하면 좋은 말 / 피할 말" — 실제 문장 예시 각 2개.
4. **잘 맞는 일주 3개**는 짝마다 이유를 따로 쓴다(두 일주의 이름을 넣고, 왜 맞는지 장면 하나). 같은 이유 문장을 다른 짝에 재사용 금지.
5. FAQ는 3개로 늘리고, **"실제 궁합은 여덟 글자 전체가…" 같은 공통 안내는 페이지 맨 아래 공통 문구(컴포넌트)로 한 번만** 두고 데이터에서는 뺀다(페이지마다 같은 문장이 들어가는 걸 막는다).
6. 기존 규칙 유지: 한자·전문용어 금지(일주 이름 예외), 단정적 예언 금지("~하는 편이에요", "~하기 쉬워요"), 요청 때마다 AI 호출 금지(정적 데이터), 생년월일을 URL에 넣지 않기.
7. 생성은 AI로 해도 되지만 **60장을 한 번에 같은 프롬프트로 찍지 말고**, 일주마다 위 1번의 고유 근거를 프롬프트에 넣어 따로 만든 뒤 아래 검사를 통과시킨다.

## 반드시 추가할 테스트 — `tests/iljuUniqueness.test.ts`
아래 검사가 통과하지 못하면 푸시하지 않는다.

```ts
import { describe, it, expect } from "vitest";
import { ILJU_LIST } from "@/lib/seo/ilju";

function pageTexts(d: (typeof ILJU_LIST)[number]): string[] {
  const t: string[] = [d.headline, d.summary];
  const s = d.sections;
  for (const sec of [s.loveStyle, s.innerMind, s.breakupReunion]) t.push(...sec.subheadings.map((x) => x.body));
  t.push(s.bestMatches.intro, ...s.bestMatches.matches.map((m) => m.reason));
  t.push(...d.faq.map((f) => f.a));
  return t;
}
const sentences = (t: string) =>
  t.split(/(?<=[.!?요다])\s+/).map((x) => x.trim()).filter((x) => x.length > 15);

describe("일주 페이지 고유성", () => {
  const perPage = ILJU_LIST.map((d) => pageTexts(d).flatMap(sentences));
  const count = new Map<string, number>();
  for (const page of perPage) for (const s of new Set(page)) count.set(s, (count.get(s) ?? 0) + 1);

  it("60장이다", () => expect(ILJU_LIST).toHaveLength(60));

  it("페이지마다 본문 3,500자 이상", () => {
    for (const [i, d] of ILJU_LIST.entries()) {
      const chars = pageTexts(d).join("").length;
      expect(chars, d.name).toBeGreaterThanOrEqual(3500);
      void i;
    }
  });

  it("다른 페이지와 겹치는 문장이 전체의 15% 이하", () => {
    const total = perPage.reduce((n, p) => n + p.length, 0);
    const shared = perPage.reduce((n, p) => n + p.filter((s) => (count.get(s) ?? 0) > 1).length, 0);
    expect(shared / total).toBeLessThanOrEqual(0.15);
  });

  it("한 페이지 안에 같은 문장이 두 번 나오지 않는다", () => {
    for (const [i, page] of perPage.entries()) {
      expect(new Set(page).size, ILJU_LIST[i].name).toBe(page.length);
    }
  });

  it("잘 맞는 일주 이유 문장은 모두 다르다", () => {
    const reasons = ILJU_LIST.flatMap((d) => d.sections.bestMatches.matches.map((m) => m.reason));
    expect(new Set(reasons).size).toBe(reasons.length);
  });
});
```
