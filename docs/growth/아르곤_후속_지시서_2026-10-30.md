## 19. 공유 방문자에게 "나도 궁합 보기"를 위로 — `argon/19-share-new-compat`
**목적:** 공유 링크로 들어온 사람이 맨 아래까지 내려가지 않아도 자기 궁합을 시작하게 한다.

- `components/CompatResultClient.tsx`
  - `refToken`이 있고 결제 전(`!isPremium && !unlockToken && !deepReport`)일 때, 점수 카드 바로 아래에 작은 카드 하나를 둔다.
  - 문구: "나도 그 사람과 30초 무료 궁합 보기 →"
  - 링크: 맨 아래 기존 링크와 같은 `/${locale}/compat/new?ref=${encodeURIComponent(refToken)}`
  - 초대 수령자(`isInviteReceiver`)에게는 띄우지 않는다. 이미 전용 카드가 있다.
  - 맨 아래 기존 링크는 그대로 둔다.
- **GA:** 클릭에 `share_visitor_new_compat_click { compatId }`. 다른 값(생년월일·이름)은 넣지 않는다.
- `app/[locale]/compat/invite/[token]/page.tsx`의 `bg-white`는 고치지 않는다. 전역 CSS가 이미 어둡게 바꾼다.
- **테스트**
  - `refToken`이 있을 때만 카드가 렌더링되는지
  - 초대 수령자·결제 후에는 안 나오는지
  - href에 compat/new와 ref 외의 값이 없는지
- **판단 기준(클로드가 본다):** 배포 후 7일간 `share_visit` 대비 클릭률과 `ref` 달린 `compat_created`.

## 20. 궁합 잠금 배너에 실제 점수가 낮은 항목 넣기 — `argon/20-compat-banner-axis`
**목적:** 결제벽이 내 결과를 읽고 말하는 것처럼 보이게 한다. 점수는 계산된 값만 쓴다.

- `components/CompatResultClient.tsx`의 상단 배너("우리가 부딪히는 지점 3가지 보기") 한 곳만 바꾼다.
- `lib/compatGauge.ts`에 순수 함수를 추가한다: `lowestPublicAxis(publicBreakdown)`
  - `pickPublicBreakdown` 결과의 세 항목(stem/balance/yinYang)을 `점수 ÷ max` 비율로 비교해 가장 낮은 항목의 `{ label, score, max }`를 돌려준다.
  - 비율이 같으면 `COMPAT_GAUGE_SPECS` 순서상 앞선 항목. 값이 없으면 null.
- 배너 문구
  - 제목: `우리 '${label}' ${score}/${max}점, 어디서 부딪힐까?`
  - 설명 줄은 지금 문구를 유지한다: "풀어 가는 법 · 이번 달 애정운 타이밍까지 전체 리포트로"
  - null이면 지금 제목을 그대로 쓴다.
  - 390px에서 제목이 잘리지 않는지 확인한다.
- 지어낸 수치, "○○% 위험" 같은 표현, 단정적 예언, 한자·전문용어를 쓰지 않는다. 점수 산식(`lib/compatibility.ts`)은 건드리지 않는다.
- **GA:** `click_top_cta`에 `banner: "axis"|"default"`만 추가한다. 이벤트 이름은 바꾸지 않는다.
- **테스트**
  - 같은 입력 = 같은 항목(결정론), 비율 계산(30점 만점과 10점 만점을 점수로 비교하지 않는지), 동점, null
  - 배너 문구에 금지 용어가 없는지
- **판단 기준(클로드가 본다):** 배포 전후 7일의 `view_paywall` 대비 `click_top_cta` 비율과 `compat_basic` 결제 수. 19번 배포 후 최소 3일 뒤에 배포한다(한 번에 하나씩 비교).
