## P-016-2 무료 결과 + 입력
파일: `components/CompatResultClient.tsx`, `components/CompatNewClient.tsx`, `components/report/TeaserUnlockPanel.tsx`
1. **잠긴 점수 칸 3개**: 무료 궁합 결과에 "속마음 ??? · 표현 방식 ??? · 다툼 회복 ???" 카드(유료 상품의 실제 항목명). 누르면 해당 상품 미리보기로(`nextReadingHref`). 이벤트 `locked_card_click`.
2. **끊긴 문장**: 무료 요약 마지막 문장을 "그런데 그 사람은…"처럼 이어지게 자르고 그 아래 미리보기 버튼. 
3. **핵심 단어 가리기**: 미리보기·결과 예시의 잠긴 부분에서 핵심 단어를 `●●●`로 가린 문장 1~2줄 노출(예: "그 사람은 당신의 ●●●에 가장 끌려요"). 원문 단어는 브라우저로 보내지 않기(서버에서 가린 뒤 전달).
4. **정직한 위치 표시**: 점수 분포(전체 1,177쌍, 중앙값 86, 상위 25% = 91, 상위 10% = 94)로 계산해 **상위 30% 이내일 때만** "상위 N% 궁합" 표시. 계산은 점수만으로 결정론 함수(`lib/compatPercentile.ts` + 단위 테스트).
5. **눌러서 공개**: 궁합 점수가 나오기 전 "분석 끝! 눌러서 확인하기"(콩이·닥이 하트) 한 번 누르면 점수가 올라가는 연출. 이벤트 `score_reveal_click`. `compat_created`는 지금처럼 결과 생성 시점에 발사(공개 클릭과 무관).
6. **대화형 입력**: 한 화면에 질문 하나씩(나 → 상대 → 관계 → "지금 제일 궁금한 것" 1개 선택: 그 사람 마음 / 다시 만날 수 있을지 / 오래 갈지 / 다툼 이유). 관계는 지금 3가지 유지 + 선택값은 **AI 문장 말투에만** 반영(점수 영향 없음). 생일 칸 아래 "생일은 암호화돼 저장돼요" 문구.
