## 1. 홈 큰 카드: PC에서 넘기기 (`components/home/HomeHeroCompact.tsx`)
- 마우스 화면에서만(`[@media(hover:hover)_and_(pointer:fine)]`) 카드 좌우에 원형 ‹ › 버튼(40px, 반투명 어두운 배경 + 흰 화살표, `aria-label="이전/다음 카드"`). 첫 장에서 ‹, 마지막 장에서 › 는 흐리게+비활성.
- 누르면 `scrollerRef.current.scrollTo({ left: 카드폭*idx, behavior: "smooth" })`.
- 카드 아래 점 4개(현재 = 코랄 길쭉, 나머지 = 흰색 30%). 점도 누르면 해당 카드로 이동. 점은 모바일·PC 모두 표시. 우상단 "1 / 4" 알약은 유지.
- 자동 넘김 없음. 이벤트 `home_hero_nav { via: "arrow" | "dot", to }`.
- 모바일 손가락 넘김 동작은 지금과 똑같이.

- 4장: **① 그 사람 속마음(inner_mind) ② 2027 신년운(annual_2027) ③ 2027 대운(premium_2027_daeun) ④ 정통 궁합(compat_basic)**. 솔로·재회 슬라이드는 뺀다.

- ③ 대운 카드: 상황 라벨 "2027 대운 · 프리미엄", 금색 배지 2개를 **둘 다** 표시(`프리미엄` + `연말 특가 · 12/31까지`). 하단에 `19,900원` 취소선 + `9,900원`(값은 `product.originalPrice`/`product.price`에서 읽기, 숫자 하드코딩 금지 — 특가 끝나면 자동으로 취소선이 사라져야 함). 표지 `/covers/cover_premium_2027_daeun.webp`, 링크는 상품 상세(`resolveProductHref` 또는 기존 상품 링크 규칙).

## 3. 포스터 카드: 글을 사진 아래로 (`components/cards/KongdakCards.tsx` `PosterCard`)
- 사진(표지) 영역은 위쪽 **4:5**, 그 아래 별도 어두운 칸(`#22142A`)에 글. 사진 위 어두운 그라데이션 덮개 제거(사진이 가려지지 않게). 사진 위에는 배지만.
- 아래 칸: 제목 1줄(15px 굵게) + 설명 1줄(`line-clamp-1`, 12px) + 오른쪽 아래 가격 작게(11px, `#B9A9BF`). 특가 상품은 취소선 원가 + 금색 특가가.
- 카드 안 **"무료 미리보기" / "지금 바로 무료" 글자 제거**. 대신 홈 목록 제목 줄 오른쪽에 작은 글씨 "모든 풀이 무료 미리보기" 한 번.
- 무료 상품은 가격 자리에 "무료".
- **배지 규칙 변경**: 특가 중인 프리미엄 상품도 `프리미엄` 배지를 같이 보여 준다(지금은 특가면 프리미엄이 숨겨짐).
- 세트 카드(`SetStackCard`)는 그대로.
- 2칸 격자에서 카드 높이가 들쭉날쭉하지 않게(글 칸 고정 높이).
