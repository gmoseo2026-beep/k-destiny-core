## 2. 【나레이터】 완치 ✅ — 128 → 206 Hz

**78 Hz 상승.** 남성 음역대(85–155)에서 **여성 음역대(165–220) 정중앙**으로 이동했습니다.
프롬프트에서 저음 형용사를 빼고 `unmistakably female` 을 앞세운 게 정확히 먹혔습니다.

v2와 v3가 **206.1 Hz로 완전히 동일**합니다 — 같은 보이스가 두 모델에서 일관되게 재현된다는 뜻이라 좋은 신호입니다.
차이는 길이(10.53s vs 9.87s)와 밝기(1587 vs 1687)뿐입니다. v3가 약간 빠르고 밝습니다.

**통과 기준(165 Hz 이상) 충족.** 더 손댈 필요 없습니다.

## 3. 【Karma v3】 압도적 개선 ✅ — v3를 쓰셔야 하는 결정적 증거

### 침묵이 드디어 구현됐습니다

```
Karma 1차       무음 14.8%  긴침묵 2회  [0.18, 0.28]
Karma 2차 v2    무음 17.0%  긴침묵 4회  [0.18, 0.54, 0.26, 0.22]
Karma v3        무음 41.5%  긴침묵 5회  [1.76, 1.20, 0.68, 1.54, 0.66]   ← 진짜 여백
```

**v2는 `…` 를 0.5초 이하로 흘려버렸는데, v3는 1.76초·1.54초의 진짜 침묵으로 해석했습니다.**
목표 25%를 크게 넘겼습니다.

### 역설적인 사실 — v3가 더 느린 설정이 아닌데 더 깁니다

v2는 Speed **0.85**, v3는 **0.90** 인데 길이는 v3가 **15.73초 vs 14.03초로 더 깁니다.**
발화 속도는 v3가 빠른데 **침묵이 그 차이를 뒤집었다**는 뜻입니다.

→ **"너무 느려서 0.90으로 올렸다"는 판단이 정확했습니다.** v3에서는 속도를 늦출 필요가 없습니다.
침묵이 여백을 만들어주니까요. 오히려 **발화 자체는 또렷하게, 침묵으로 무게를 주는** 게 더 좋은 연출입니다.

### 음높이도 올라갔습니다

162 → **179 Hz**. 여성 알토 정상 범위로 들어왔고, 밝기도 2049로 가장 선명합니다.

## 4. 【Seoa】 재생성이 안 됐습니다 ❌

**MD5 해시가 1차 파일과 완전히 동일합니다.**

```
6d4a19d08e2c356521065c2dd1710460   [1차] Seoa test.mp3
6d4a19d08e2c356521065c2dd1710460   [2차] Seoa test.mp3   ← 같은 파일
```

측정값도 소수점까지 동일(152.1 / 150.7 / 22.7% / 979)합니다. 같은 파일을 다시 올리신 것 같습니다.

**Seoa는 여전히 두 가지가 문제입니다.**

- **F0 152 Hz** — 남성 음역대. 스펙(~200)보다 48 Hz 낮습니다
- **밝기 979 Hz** — 셋 중 압도적으로 어둡고 먹먹합니다. 스펙이 **"또렷하고 발음이 정확한"** 이었으니 정반대입니다

## 5. ★ v3 채택 권고 — 근거 4가지

| # | 근거 |
|---|---|
| 1 | **문장부호 해석이 압도적** — `…` 를 1.76초 침묵으로. v2는 0.54초가 최대 |
| 2 | **음높이가 더 높음** — Karma 162 → 179 Hz. 여성성 개선 |
| 3 | **음색이 더 선명** — 밝기 1846 → 2049 |
| 4 | **사용자님 귀에도 더 자연스러움** — 측정과 청감이 일치 |

### ⚠️ 다만 v3에는 파이프라인 리스크가 있습니다

**① 후보 2개 중 사람이 고르는 방식**

말씀하신 대로 v3는 두 버전을 만들어 하나를 선택합니다. **이건 무인 자동화와 충돌합니다.**
`tts.py` 를 API로 짤 때 이 단계가 어떻게 동작하는지 확인해야 합니다.

- API의 `eleven_v3` 는 요청당 오디오 1개를 반환하는 것으로 보이지만(문서에 다중 반환 언급 없음),
  **웹 UI의 "2개 중 선택"이 API에도 있는지는 확인되지 않았습니다**
- 만약 API가 1개만 준다면 → **웹 UI에서 고른 것만큼의 품질이 안 나올 수 있습니다**
- 대응: 첫 배치에서 **API 결과를 웹 UI 결과와 비교**해보고, 차이가 크면
  API에서 **같은 텍스트를 2회 생성해 긴 쪽(침묵이 살아있는 쪽)을 자동 선택**하는 로직을 넣습니다

**② v3는 SSML `<break>` 태그를 지원하지 않습니다**

침묵은 **텍스트의 `…` 와 `—`** 로만 제어됩니다. 이번 결과가 그걸 증명했으니 그대로 가면 됩니다.
`casting.json` 에 캐릭터별 **"텍스트 전처리 규칙"** 을 넣어 자동으로 `…` 를 삽입하도록 설계하겠습니다.

**③ v3는 알파/신규 모델** — 안정성과 요금이 v2와 다를 수 있습니다. 첫 달 사용량을 지켜보세요.

## 6. 남은 작업 — Seoa 하나뿐입니다

### 6-1. Seoa 재생성 (v3로)

```
An unmistakably female Korean voice, thirties, bright and crystal-clear with
crisp articulation — every consonant distinct and forward. Intelligent and
composed, like a thoughtful counselor explaining something carefully.
Natural feminine pitch, noticeably brighter than an alto. Never dark,
never muffled, never breathy. Even, unhurried delivery.
```

**설정:** Speed **1.00** · Stability **Robust** · 모델 **v3**

**테스트 텍스트** (Karma와 대비되도록 침묵 없이 또렷하게)
```
인연은 우연이 아니라 타이밍입니다. 계산이 되거든요.
```

**통과 기준**
- F0 **190 Hz 이상** (Karma 179와 최소 1.5반음, 나레이터 206과도 구별)
- 밝기 **1600 Hz 이상** (현재 979 → 최소 1.6배)

### 6-2. 목표 음높이 배치 (여성 5인 + 나레이터)

같은 영상에 마스터 3명이 함께 나오므로 **F0를 계단식으로** 벌려두면 좋습니다.

| 캐릭터 | 목표 F0 | 현재 |
|---|---|---|
| Karma (낮은 알토) | 170–180 | ✅ **179** |
| Yura (풍부한 알토) | 180–190 | 미생성 |
| Rin (우아한 메조) | 190–200 | 미생성 |
| **Seoa (또렷한 메조)** | **195–205** | ❌ 152 |
| 나레이터 | 200–210 | ✅ **206** |
| Hana (밝은 소프라노) | 215–230 | 미생성 |

> Seoa와 나레이터가 가깝지만, **나레이터는 후크·CTA만, 마스터는 본문**을 맡아 역할이 분리되고
> 밝기·속도도 다르므로 실사용에서는 구별됩니다. F0만으로 6명을 벌릴 필요는 없습니다.

### 6-3. ★ 아직 안 하신 것 — 영어 테스트

**두 라운드 모두 한국어만 주셨습니다.** 한/영 2채널 전략의 핵심 전제가 이거였습니다.

> 같은 Voice ID로 낸 한국어와 영어가 **같은 캐릭터로 들리는가**

Seoa 재생성하실 때 **나레이터·Karma·Seoa 각각 영어 한 문장씩** 함께 뽑아주세요.

```
[Narrator] Your horoscope has twelve options. Korean Saju has 518,400.
[Karma]    If you were born in 1996 — stop scrolling for five seconds.
[Seoa]     Connection isn't chance. It's timing — and timing can be calculated.
```

이게 통과하면 영어 채널 보이스를 **따로 만들 필요가 없습니다**(작업량 절반).
안 되면 영어용 11개를 별도 디자인해야 합니다(비용은 같지만 시간 2배).

## 7. 제가 판단 못 하는 것 — 확인해주세요

- [ ] **`1996년생` 을 "천구백구십육년생"으로 제대로 읽는가** (숫자 오독은 치명적)
- [ ] 받침·연음이 자연스러운가
- [ ] **나레이터가 이제 확실히 여성으로 들리는가** (측정상 206 Hz로 정상)
- [ ] Karma v3의 1.76초 침묵이 **어색하게 늘어지지 않는가** (측정상 좋지만 청감은 다를 수 있음)

> 4번이 특히 중요합니다. 무음 41.5%는 데이터상 훌륭하지만, 22초 숏폼에서 1.76초 침묵이 **두 번**이면
> 시청자가 이탈할 수도 있습니다. **실제 영상 길이에 맞춘 짧은 대사로 한 번 더** 들어보세요.
