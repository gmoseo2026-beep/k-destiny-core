# 리타게팅 광고 — "미리보기만 보고 안 산 사람"에게 다시 보여 주기 (2026-10-27)

- 매일 약 100명이 무료 미리보기를 보고, 그중 90% 넘게가 결제 없이 나가요.
- 이 사람들은 이미 관심을 보인 손님이라, 새 손님을 찾는 광고보다 결제율이 훨씬 높아요.
- 사이트의 메타 픽셀에 "미리보기(Lead)", "결제창 열기(InitiateCheckout)", "구매(Purchase)"가 10/7부터 쌓이고 있어서 바로 만들 수 있어요.
- 같은 생년월일이면 결과가 같아요. 그래서 다시 들어와 생일을 넣으면 그때 본 미리보기가 그대로 이어져요. 광고 문구에 이 점을 써요.

**순서:** 메타 먼저 하고(하루 5,000원), 틱톡은 3~4일 뒤 결과를 보고 해요.

---

## A. 메타

### 1단계. 맞춤 타겟 만들기 (한 번만)
1. 광고 관리자 왼쪽 **≡ 메뉴 → "타겟"**(Audiences)으로 들어가요.
2. **[타겟 만들기] → 맞춤 타겟 → 소스: 웹사이트**를 골라요.
3. **소스: 콩닥 픽셀 (2390478744821136)**
4. **포함:** "다음 중 하나라도 충족하는 사람"
   - 이벤트 **Lead**, 보관 기간 **30일**
   - [포함 조건 추가] → 이벤트 **InitiateCheckout**, **30일**
5. **[사람 제외]** → 이벤트 **Purchase**, **30일**
6. 이름은 **RT_미리보기_미구매_30일**로 하고 **[타겟 만들기]**를 눌러요.
7. 규모가 "준비 중"으로 나오면 몇 시간 뒤에 숫자가 나와요. 1,000명 이상이면 충분해요.

### 2단계. 새 캠페인 (기존 여성 캠페인과 따로)
| 항목 | 값 |
|---|---|
| 목표 | 판매 → 수동 판매 캠페인 (지난번과 같은 방식) |
| 캠페인 이름 | `콩닥_메타_리타게팅_1027` |
| 예산 | **광고 세트 예산**, 20% 공유 체크 해제 |

### 3단계. 광고 세트
| 항목 | 값 |
|---|---|
| 이름 | `RT_미리보기_미구매` |
| 전환 위치 · 데이터 세트 · 이벤트 | 웹사이트 · 콩닥 픽셀 · **구매** |
| 일일 예산 | **5,000원** |
| 타겟 | **"광고 도달에 제한 추가" → 맞춤 타겟 → `RT_미리보기_미구매_30일`** (꼭 "제한"으로 넣어요. "추천"으로 넣으면 다른 사람에게도 나가요) |
| 위치 · 언어 | 대한민국 · 한국어 · 최소 연령 18 (성별은 정하지 않아요. 이미 관심을 보인 사람들이라서요) |
| 노출 위치 | 지난번과 같아요. **플랫폼은 Facebook · Instagram만.** Threads · WhatsApp · Audience Network · Messenger는 해제해요 |

### 4단계. 광고 2개
공통 설정: 대표 계정은 **Facebook 페이지 "콩닥"**, Instagram은 **"Facebook 페이지 사용"**이에요. CTA는 **더 알아보기**이고, 자동 개선(Advantage+ 크리에이티브)은 전부 꺼요.

| 광고 이름 | 영상 (`2차/`) | 기본 문구 | 제목 | URL |
|---|---|---|---|---|
| RT1 | `BN2.mp4` | 그 사람 속마음, 미리보기에서 멈췄다면? 잠긴 이야기 3개가 아직 남아 있어요. 같은 생일이면 결과도 같아서, 다시 넣으면 그때 그 이야기가 그대로 이어져요. | 그때 본 속마음, 이어서 보기 | `https://kongdak.kr/ko/go/ig-rt1` |

- 문구에 "당신은 ~했죠" 같은 표현을 쓰지 않았어요. 메타는 광고가 개인의 행동이나 특성을 안다고 말하는 걸 금지해요.
- 금액도 넣지 않았어요.

### 5단계. 게시 전 확인
- 광고 세트의 타겟이 **"맞춤 타겟: RT_미리보기_미구매_30일"(제한)**으로 되어 있나요?
- 예산이 **5,000원**인가요?
- 노출 위치에 Threads가 빠져 있나요?

## B. 틱톡 (3~4일 뒤, 메타 결과를 보고)
틱톡은 맞춤 오디언스가 **1,000명 이상**이어야 광고가 나가요.
1. 도구 → **오디언스 → 만들기 → 맞춤 오디언스 → 웹사이트 트래픽**으로 들어가요.
2. 픽셀 **콩닥**을 고르고 "특정 이벤트를 수행한 방문자"에서 **양식 제출(SubmitForm) 30일 + 체크아웃 시작 30일**을 포함해요.
3. **구매 완료(CompletePayment) 30일**은 제외해요.
4. 새 캠페인(판매 → 웹사이트, 수동)의 광고 그룹 오디언스에 이 맞춤 오디언스를 넣어요.
5. 광고는 BN2 영상에 RT1과 같은 문구로 만들고, URL은 `https://kongdak.kr/ko/go/tt-rt1`이에요.
